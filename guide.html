安裝與開通

一次部署，全企業啟用

IT 於伺服器執行一個安裝檔並匯入原廠授權，即可開始使用。 Agent 由使用者自行下載安裝，無須 IT 逐台部署。

IT 管理員

伺服器端

  1. 準備安裝檔與授權檔

    安裝檔（MetricPortalSetup-*.exe） 自下載頁取得；授權檔（license.json） 由原廠另行提供。授權檔綁定貴企業，因此不在公開下載頁提供。

  2. 安裝

    以系統管理員身分執行安裝檔。安裝過程僅需設定以下兩項：

    連線設定：選擇 HTTP 或 HTTPS 及連接埠。無特殊需求可直接採用預設值。

    授權檔：選取 license.json。 可暫時留空，安裝後於後台上傳。

  3. 登入後台並變更預設密碼

    以瀏覽器開啟 https://伺服器位址:8788，使用預設管理員帳號登入。 首次登入後，請立即變更預設密碼。

    「版本與授權 → 授權與續約」顯示授權狀態：剩餘天數、已開通人數，以及綁定的機器。

  4. 設定模型

    於「模型 → 供應商與閘道」設定要使用的模型，可為企業自行部署的模型， 或外部供應商的 API 金鑰。金鑰僅存放於此伺服器，不會下發至使用者電腦。

  5. 提供下載連結給使用者

    https://伺服器位址:8788/downloads

    Portal 安裝時已一併部署 Agent 安裝檔，此頁面開啟即可下載， 無須另行準備。

使用者

使用者端

  1. 自內部下載頁取得安裝檔

    開啟 IT 提供的企業內部網址。自該頁下載的安裝檔已內建伺服器位址， 無須手動輸入。

  2. 安裝

    無須系統管理員權限，使用者可自行安裝。安裝過程會下載執行環境，電腦須具備網路連線。

  3. 送出申請

    首次啟動時填寫姓名（或企業帳號，依 IT 設定而定）並送出。

  4. 等候 IT 核准

    IT 於後台核准後即可開始使用。每位使用者對應一台機器； 更換電腦前，須先請 IT 停用舊機器。

授權

授權由原廠核發

授權檔僅規範兩項：席次數與到期日。 授權檔經原廠簽章，任何一個位元組遭變更即失效；請保留原檔，勿自行編輯。

情境處理方式
首次開通原廠提供授權檔，於安裝時匯入，或安裝後於後台上傳
續約原廠提供新授權檔，於「版本與授權 → 授權與續約」點選「上傳授權檔」，立即生效，無須重新啟動
增加席次告知原廠所需席次數，由原廠核發新的授權檔
伺服器遷移將新伺服器後台顯示的「本機識別碼」提供給原廠，由原廠核發綁定新機器的授權檔

授權到期當日即停止服務。到期前 30 天起，後台會開始提醒； 若已設定郵件通知，亦會寄送通知信。 請注意：到期時所有使用者將同時無法連線，並非僅限制新加入的使用者， 請提前完成續約。

更新

兩種更新模式

離線（出廠預設）

伺服器完全不對外連線。新版本由原廠提供更新檔，IT 於後台上傳。 適用於不允許對外連線的機房環境。

線上

伺服器每 6 小時自動檢查一次新版本，有新版時於後台提示。 是否下載與安裝，仍須由 IT 手動執行。

啟用線上模式時，防火牆須放行以下三個網域：api.github.com、 github.com、release-assets.githubusercontent.com。 每次檢查僅發出一個查詢請求。

使用者電腦的更新一律由企業自有的伺服器派送，使用者端完全不對外連線。 派送時間與對象由 IT 決定。

疑難排解

狀況排查方式
使用者無法連線檢查後台「版本與授權 → 授權與續約」：授權到期或席次已滿皆會顯示於此（儀表板頂端亦會提示）
安裝後詢問要連線的伺服器該安裝檔並非自企業內部下載頁取得。請由 IT 提供的內部網址重新下載
檔案雜湊值與原檔不符屬正常現象：檔案尾端已寫入貴企業伺服器的位址
授權顯示「綁定不符」通常因更換伺服器或執行災難復原所致。請將「本機識別碼」提供給原廠，重新核發授權檔
